# Contributing to Naruto RPG Godot

Terimakasih telah tertarik untuk berkontribusi! 🎉

## Cara Berkontribusi

### 1. Fork Repository
```bash
git clone https://github.com/YOUR-USERNAME/naruto-rpg-godot.git
cd naruto-rpg-godot
```

### 2. Buat Branch Baru
```bash
git checkout -b feature/AmazingFeature
```

### 3. Buat Perubahan
- Edit files sesuai kebutuhan
- Test perubahan di Godot
- Commit dengan pesan yang jelas

### 4. Push ke GitHub
```bash
git add .
git commit -m "Add AmazingFeature"
git push origin feature/AmazingFeature
```

### 5. Buat Pull Request
- Buka GitHub repository
- Klik "New Pull Request"
- Jelaskan perubahan Anda
- Tunggu review

## Guidelines

### Code Style
- Gunakan GDScript dengan naming convention: snake_case untuk variables & functions
- Tambahkan comments untuk kode kompleks
- Organize code dengan proper indentation (1 tab = 4 spaces)

### Commit Messages
```
[TYPE]: Description

TYPE dapat berupa:
- feature: Fitur baru
- fix: Bug fix
- docs: Dokumentasi
- style: Code style
- refactor: Refactoring
- test: Testing

Contoh:
feature: Add skill combo system
fix: Fix player movement bug
docs: Update BUILD_APK.md
```

### Testing
- Test di Godot Editor sebelum push
- Test di Android device jika possible
- Pastikan tidak ada console errors

### Documentation
- Update README jika menambah fitur
- Tambahkan comments untuk kode
- Update BUILD_CHECKLIST.md jika ada perubahan build

## Bug Reports

Jika menemukan bug:
1. Buka GitHub Issues
2. Jelaskan bug dengan detail
3. Sertakan steps to reproduce
4. Attach error logs/screenshots

## Feature Requests

Untuk saran fitur:
1. Buka GitHub Issues dengan label "enhancement"
2. Jelaskan fitur yang diinginkan
3. Jelaskan use case
4. Tunggu feedback dari maintainers

## License

Dengan berkontribusi, Anda setuju bahwa kontribusi Anda akan di-license di bawah LICENSE project ini.

## Questions?

Buka issue dengan label "question" atau hubungi maintainers di Discord.
